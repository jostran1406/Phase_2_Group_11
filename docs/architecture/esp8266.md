## 2. Overview

The ESP8266 module acts as the communication bridge between the STM32
microcontroller and the backend server. It receives sensor data from
STM32 via UART, then transmits that data to the backend through WiFi
using the MQTT/HTTP protocol. It is also responsible for receiving
control commands from the backend and forwarding them back to STM32.

## 3. Responsibilities

- Receive sensor data (temperature, humidity, gas, light) from STM32 via UART.
- Connect to WiFi network and maintain a stable connection.
- Publish sensor data to the backend using MQTT (or send via HTTP request).
- Subscribe to control topics / receive commands from backend.
- Forward control commands to STM32 via UART.
- Handle reconnection when WiFi or MQTT connection is lost.

## 4. Module Diagram

![ESP8266 Module](esp8266-module.png)

Main modules:
- **WiFi Manager**: handles WiFi connection and reconnection.
- **MQTT/HTTP Client**: handles publishing sensor data and receiving commands.
- **UART Handler**: communicates with STM32 (send/receive data frames).
- **Data Parser**: parses data frames between STM32 format and MQTT/HTTP payload.

## 5. Communication Flow

![ESP8266 Flow](esp8266-flow.png)

1. STM32 sends sensor data to ESP8266 via UART.
2. ESP8266 parses the data and publishes it to the backend via MQTT/HTTP.
3. Backend sends control commands to ESP8266 via MQTT/HTTP.
4. ESP8266 parses the command and forwards it to STM32 via UART.
