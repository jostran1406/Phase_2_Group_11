# Project Plan

## 1. Introduction

### 1.1 Purpose

This document describes the project planning activities for the **Environmental Monitoring and Control System for Laboratory Using IoT**. It defines the project objectives, project scope, development methodology, work breakdown structure, sprint planning, project schedule, and team responsibilities.

### 1.2 Project Overview

| Item | Description |
|------|-------------|
| Project Name | Environmental Monitoring and Control System for Laboratory Using IoT |
| Version | Phase 2 |
| Project Area | Electronic Laboratory |
| Monitoring Scope | Laboratory (~60 m²), 03 IoT Nodes |
| Team Members | Nhân, Khánh, Nghĩa, Kiên |
| Development Method | Agile (03 Sprints) |

---

## 2. Project Objectives

The objectives of the project are:

- Monitor environmental parameters in real time.
- Collect and store sensor data.
- Visualize data through a web dashboard.
- Support automatic device control.
- Provide remote monitoring and user interaction.

---

## 3. Development Methodology

The project follows the Agile software development methodology and is divided into three sprints.

### Sprint 1

Focuses on project planning, documentation, software architecture, and development environment setup.

### Sprint 2

Focuses on firmware, backend, frontend implementation, and system integration.

### Sprint 3

Focuses on testing, optimization, documentation, and final demonstration.

---

## 4. Work Breakdown Structure (WBS)

The project is divided into the following work packages:

- Project Planning & Documentation
- Firmware Development
- IoT Communication
- Backend & Dashboard Development
- Control & System Testing
- Project Completion

Refer to the WBS document for detailed task allocation.
