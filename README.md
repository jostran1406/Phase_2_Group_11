# IoT Laboratory Environment Monitoring and Control System

## Overview
This project develops an IoT-based monitoring and automatic control system for laboratory environments.
The system monitors environmental conditions using multiple IoT sensor nodes and provides a web dashboard for real-time monitoring, historical data visualization, automatic control and alert management.

## Features
- Temperature monitoring
- Light intensity monitoring
- Air quality monitoring
- Real-time dashboard
- Historical data
- Automatic fan control
- Automatic lighting control
- Alert notification
  
## System Architecture
STM32 -> ESP8266 -> WiFi -> Backend Server -> Database -> Dashboard
